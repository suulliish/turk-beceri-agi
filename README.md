# Türk Dünyası Beceri Ağı — Локальный дубль

Точная 1:1 автономная локальная копия сайта **Türk Dünyası Beceri Ağı** (Оригинал: https://miraykyn.github.io/turk-beceri-agi/).

## Структура проекта
```text
turk-beceri-agi/
├── index.html          # Главная страница (разметка, CSS-стили, JS-логика, AI Turan)
├── assets/
│   └── flags/          # Локальные векторные SVG-флаги 7 тюркоязычных стран
└── README.md           # Документация и инструкция по запуску
```

## Автономность
Все внешние графические ресурсы (векторные флаги стран с Wikimedia Commons) сохранены локально в папке `assets/flags/`. Сайт полностью функционирует без необходимости подключения к серверам Wikimedia.

## Способы запуска

### Способ 1: Прямое открытие в браузере
Просто дважды кликните по файлу `index.html` или откройте его через браузер (Safari, Chrome, Edge, Firefox).

### Способ 2: Через локальный веб-сервер (рекомендуется)
Для корректной работы всех механизмов (включая работу с относительными путями и API перевода) выполните в терминале из папки проекта:

```bash
# Перейдите в папку проекта:
cd "turk-beceri-agi"

# Запустите локальный сервер через Python:
python3 -m http.server 8000
```

После этого откройте в браузере:  
👉 **http://localhost:8000**
